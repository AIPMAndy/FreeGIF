# FreeGIF｜产品路线图

## 核心定位

第一性原理：让普通人最低成本把静态图片变成可用的动态内容。区别于高阶 AI 动画工具，先解决 **零安装、手机可用、本地隐私、导出可靠**。

## V0.1｜已完成

- [x] 独立 HTML 网页（本地 Canvas 渲染、GIF89a 编码）
- [x] 移动端响应式与实时预览
- [x] 六类轻动效：漂浮 / 弹跳 / 摇摆 / 呼吸 / 双图切换 / 打字标题
- [x] 图片、文案、背景、署名与画幅设置
- [x] Python CLI 与 Codex Skill
- [x] GitHub Pages Actions 工作流
- [ ] 线上 Pages 实际部署与手机真机复测（依赖发布状态）

## V0.2｜增长验证优先

- [ ] 批量生成 9 / 16 / 24 张 GIF，并 ZIP 下载
- [ ] 微信表情平台规格校验（根据官方最新要求）
- [ ] 透明底动图与封面成套导出
- [ ] iOS Safari / 安卓低内存设备回归
- [ ] GIF 文件体积优化和 Web Worker 编码

## V0.3｜提升表达能力

- [ ] 用户自定义缓动、关键帧和时间轴
- [ ] 更多动效和版权安全的模板
- [ ] 像素画及贴纸风格
- [ ] WebP / APNG 导出（单独实现并验收）

## V1.0｜按需验证

- [ ] 可选接入 AI 生成动作帧和角色表情包，不偷换成图片整体变形
- [ ] 商用品牌短片 / 竖版宣传图模板
- [ ] 围绕真实用户问题做教程和案例库

## 商业化原则

不强制订阅、不增加原图上传，不强制水印。优先用开源的体验建立口碑；公司信息只在页脚和 README 自然出现。指标以真实可验证的 GIF 导出成功率、反馈和复用为主，不编造数据。
